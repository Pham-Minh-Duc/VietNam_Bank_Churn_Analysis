[REQ-2] Define Success Metrics & Deliverables

Nội dung: Chốt các kết quả bàn giao (SQL script, Excel report, Power BI Dashboard, Recommendations).

Phase 2: Data Collection & Ingestion
[DAT-1] Inspect Raw Data & Validate Schema

Nội dung: Dùng Python/Pandas kiểm tra sơ bộ kiểu dữ liệu, missing values và tổng quan 10,000 dòng dữ liệu thô.

[DAT-2] Set up MySQL Database & Load Raw Data

Nội dung: Tạo database bank_analytics_db và nạp dữ liệu thô vào bảng raw_bank_churn trong MySQL.

Phase 3: SQL Engineering & Data Transformation
[SQL-1] Data Cleaning & Deduplication

Nội dung: Viết SQL kiểm tra bản ghi trùng, xử lý null và chuẩn hóa định dạng các cột.

[SQL-2] Feature Engineering & Category Grouping

[EDA-1] Analyze Demographic Impact on Churn Rate

Nội dung: Truy vấn SQL phân tích mối liên hệ giữa Churn với Độ tuổi, Giới tính, Vùng miền.

[EDA-2] Analyze Behavioral & Product Metrics

Nội dung: Đánh giá tác động của NumOfProducts, IsActiveMember, CreditScore tới tỷ lệ rời bỏ.

[EDA-3] Synthesize Key Insights & Financial Loss

Nội dung: Tổng hợp các phát hiện quan trọng và tính toán tổng số tiền gửi bị mất do Churn.

Phase 5: Reporting & Dashboard Development
[XLS-1] Connect MySQL to Excel via Power Query

Nội dung: Nạp dữ liệu từ MySQL View vào Excel qua Power Query.

[XLS-2] Build Pivot Tables & Financial What-If Model

Nội dung: Tạo Pivot Tables tổng hợp và xây dựng bảng mô phỏng tài chính "What-If Analysis".

[XLS-3] Create Customer Lookup & Risk Scoring Sheet

Nội dung: Dùng XLOOKUP và Conditional Formatting dựng trang tra cứu rủi ro khách hàng theo Customer_ID.
